{{ 'Goederen importeren in Suriname' if nl else 'Importing goods into Suriname' }}

{{ 'Zakelijke import loopt via de Douane in het systeem ASYCUDA. Je hebt een FIN nummer nodig, een douane-expediteur doet de aangifte, en je betaalt invoerrechten plus 10% BTW.' if nl else 'Commercial imports go through Customs in the ASYCUDA system. You need a FIN tax number, a customs broker files the declaration, and you pay import duty plus 10% VAT.' }}

{{ 'Stap voor stap' if nl else 'Step by step' }}

  1. {{ 'FIN nummer.' if nl else 'FIN number.' }} {{ 'Sinds 1 januari 2025 verplicht voor zakelijke importeurs en exporteurs. Aanvragen via het portaal van de Belastingdienst.' if nl else 'Mandatory for commercial importers and exporters since 1 January 2025. Apply through the tax office portal.' }}
  2. {{ 'Registratie in ASYCUDA.' if nl else 'Register in ASYCUDA.' }} {{ 'Eenmalig, bij de Douane.' if nl else 'Once, with Customs.' }}
  3. {{ 'Douane-expediteur.' if nl else 'Customs broker.' }} {{ 'Die dient de aangifte in met HS code, oorsprong, waarde, factuur en vrachtbrief (B/L).' if nl else 'The broker files the declaration with HS code, origin, value, invoice and bill of lading.' }}
  4. {{ 'Betalen.' if nl else 'Pay.' }} {{ 'ASYCUDA berekent de rechten; je betaalt per bank aan de Ontvanger der Invoerrechten en Accijnzen.' if nl else 'ASYCUDA calculates the duties; you pay by bank transfer to the Receiver of Import Duties and Excise.' }}
  5. {{ 'Controle en vrijgave.' if nl else 'Inspection and release.' }} {{ 'ASYCUDA kiest een spoor: rood (fysieke controle), geel (documenten), blauw (controle achteraf) of groen (direct vrij).' if nl else 'ASYCUDA picks a lane: red (physical check), yellow (documents), blue (post-clearance audit) or green (released).' }}

{{ 'Invoerrechten' if nl else 'Import duty' }}{{ 'Volgens het gemeenschappelijk CARICOM tarief, meestal 0% tot 50% afhankelijk van het product. Grondstoffen laag, eindproducten hoger; alcohol, tabak en sommige voedingsmiddelen tot 40% of 50%.' if nl else 'Based on the CARICOM common external tariff, usually 0% to 50% depending on the product. Raw materials low, finished goods higher; alcohol, tobacco and some foods up to 40% or 50%.' }}
BTW{{ '10% algemeen, ook bij invoer; 5% op brandstof, 25% op luxe goederen zoals grote auto\'s.' if nl else '10% standard, also on imports; 5% on fuel, 25% on luxury goods such as large cars.' }} {{ L('vatguide') }}
{{ 'Overige heffingen' if nl else 'Other levies' }}{{ 'Statistiekrecht en consentrecht over de CIF waarde, en accijns op alcohol en tabak. Vraag de actuele percentages aan je expediteur.' if nl else 'Statistical fee and consent fee on the CIF value, and excise on alcohol and tobacco. Ask your broker for the current percentages.' }}

{{ 'Vergunningen en verboden' if nl else 'Licences and bans' }}

  • {{ 'Vergunningplichtige goederen vraag je aan bij de Dienst Invoer-, Uitvoer- en Deviezencontrole van het ministerie van Economische Zaken.' if nl else 'Licensed goods are applied for at the Import, Export and Foreign Exchange Control service of the Ministry of Economic Affairs.' }}
  • {{ 'Medicijnen, dierenartsmiddelen en planten of dierlijke producten hebben een certificaat nodig van Volksgezondheid of LVV.' if nl else 'Medicines, veterinary drugs and plant or animal products need a certificate from Health or Agriculture.' }}
  • {{ 'Gebruikte auto\'s ouder dan 8 jaar en bussen ouder dan 15 jaar mogen niet worden ingevoerd. Uitzondering: een auto van een remigrant die minstens 2 jaar tot de verhuisboedel hoort, en klassiekers ouder dan 25 jaar.' if nl else 'Used cars older than 8 years and buses older than 15 years may not be imported. Exception: a returning migrant\'s car that has been part of the household goods for at least 2 years, and classics over 25 years.' }}
  • {{ 'Verhuisboedel van remigranten kan vrijgesteld zijn van invoerrechten. Vraag de voorwaarden vooraf bij de Douane.' if nl else 'Household goods of returning migrants can be exempt from import duty. Check the conditions with Customs in advance.' }}
